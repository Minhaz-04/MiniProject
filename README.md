# MiniProject
Meme Generator
This is a meme generator built using VsCode and it's fetching memes from an API
Technologies Used:- Html, CSS, Javascript for building the frontend. Fetched API from meme-api.com.
How it works:- - Button triggers the getMeme() function. The function uses fetch() to call the meme API.The response is then parsed to extract the meme title, author, and image URL. These details are dynamically inserted into the HTML using querySelector().
